# 手势鼠标 GestureMouse

用摄像头识别手势来控制鼠标的桌面程序：**对着摄像头比划手势，就能移动光标、单击、右键、滚轮和拖拽**。带完整图形界面，开箱即用。

![效果](https://img.shields.io/badge/status-working-brightgreen)

## 功能特点

- 🖐 **双引擎手部识别**：默认使用 MediaPipe（21 关键点，高精度）；未安装 mediapipe 时自动回退到 OpenCV 肤色识别引擎
- 🖱 **纯 Win32 鼠标控制**：ctypes 直调 `SetCursorPos` / `mouse_event`，不依赖 pyautogui
- 🎛 **图形化界面**：实时摄像头预览、灵敏度/平滑度调节、绝对/相对两种移动模式、摄像头与引擎选择、参数自动保存
- 🛡 **防误触设计**：手势防抖（保持 0.1 秒才生效）、点击冷却、手离开画面时鼠标立即静止

## 环境要求

- Windows 10/11，Python 3.10 ~ 3.14（本项目在 Python 3.14 + OpenCV 5 + MediaPipe 1.0 上实测通过）
- 一个 USB/内置摄像头

### 安装依赖

```bat
pip install -r requirements.txt
```

> 说明：`hand_landmarker.task` 是 MediaPipe 手部模型（7.8MB），已随程序附带。
> 若丢失，重新下载放到程序目录：
> <https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task>

- 双击 `启动手势鼠标.bat`
- 或命令行：`python gesture_mouse.py`

## 手势对照表

### 双手模式（默认，推荐）

**右手食指尖 = 光标**（手在画面里就持续跟踪），**左手手势 = 动作**：

| 左手手势 | 动作 |
| --- | --- |
| 🤏 拇指+食指触摸 | **单击**；**长按（约 0.5 秒）= 按住左键拖拽**，松开释放（配合右手移动 = 拖动窗口） |
| 🤏 拇指+中指触摸 | 右键单击 |
| 🤏 拇指+无名指触摸 | 上滑（持续向上滚动） |
| 🤏 拇指+小指触摸 | 下滑（持续向下滚动） |
| ✌ 左手 1 / 2 / 3 指 | 左键单击 / 右键单击 / 左键双击（备用方式，不变） |
| ✌ 左手 4 指 | 滚轮（**方向锁定**：做出手势时手在上半屏=上滚、下半屏=下滚，期间手怎么动都不改变方向；收起手势重新做即可换向） |
| ✋ 左手 5 指（张开） | **无动作**（拖拽请用拇指+食指长按） |
| 🙅 手离开画面 | 鼠标静止，绝不误触 |

> 要点：双手同时入镜、左右分开更稳定；画面里**左手显示蓝色标记、右手显示绿色标记**，黄色圆圈是光标目标点；状态栏实时显示左右手是否入镜，画面左上角 `L:几指+IDX/MID/RNG/PNK` 表示左手拇指正触碰哪个指尖。

### 单手模式（界面可切换）

| 手势 | 动作 |
| --- | --- |
| ✌ 伸出 1 指（食指） | 移动光标 |
| ✌ 伸出 2 指（食指+中指） | 左键单击 |
| ✌ 伸出 3 指（食中无名指） | 右键单击 |
| ✌ 伸出 4 指（无拇指） | 滚轮（方向锁定：做出手势时手在上半屏=上滚、下半屏=下滚） |
| ✋ 张开手掌（5 指） | 按住左键拖拽（合拢后松开） |
| 🤏 拇指+食指捏合（MediaPipe 引擎） | 按住左键拖拽（松开捏合即释放） |
| 🙅 手离开画面 / 无法识别 | 鼠标静止，绝不误触 |

**要点**：伸出的手指需要分开一些、指尖朝上，识别更稳定；保持光线充足、手部完整入镜。

## 界面说明

- **控制模式**：双手模式（右手移动·左手动作，默认）/ 单手模式（一只手全包）
- **摄像头**：auto 自动探测，也可手动指定 0~3
- **识别引擎**：auto（推荐）/ MediaPipe / 肤色识别
- **灵敏度**：绝对模式下为映射倍数（>1 手移动更少的距离就能覆盖全屏）
- **触摸灵敏度**：拇指与指尖判定为「触摸」的距离阈值。**越小越需要贴紧**（不易误触），**越大越容易触发**（但容易误判）；默认 0.55，按手感调整
- **平滑度**：越大光标越"跟手"但越抖，越小越平滑但越迟钝
- **滚轮速度**：4 指滚轮与拇指触摸上滑/下滑的滚动速度倍率（0.3~3.0，默认 1.0 ≈ 6 格/秒）
- **移动模式**：
  - 绝对定位：手指移到哪，光标就跳到屏幕对应位置（适合大屏）
  - 相对移动：像触摸板，手偏离画面中心的方向决定光标移动方向（更易精细控制）
- **右下角监视窗**：悬浮置顶在屏幕右下角的小窗，可自由拖动、拖边框调整大小。主窗口最小化后仍能看到实时手势画面：
  - 显示模式三选：**动画**（纯摄像头画面）/ **标记**（黑底手部骨架+手势文字）/ **都看**（画面+标记叠加）
  - 大字显示当前动作（如「左键单击」）并用颜色区分，下方小字说明该动作对应的具体手势
  - 窗口大小与模式自动记忆，下次启动保持
- 状态栏实时显示 FPS、当前手势、左右手是否入镜

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示"未找到可用摄像头" | 摄像头被其他程序（如会议软件）占用；或设备管理器中禁用。关闭占用程序后重试，或手动指定序号 |
| 界面提示"未检测到 mediapipe" | 执行 `pip install mediapipe`；或直接用肤色引擎（对光线和背景要求更高） |
| 光标乱跳 / 手一离开画面光标就飞 | 调高"平滑度"；确认手离开画面后界面显示"无手"（此时鼠标应静止） |
| 点击容易误触 | 手势做出后保持片刻（程序有 0.1 秒防抖 + 0.7 秒冷却），伸出的手指分开些 |
| 肤色引擎识别不到手 | 增强光线、避免穿肤色衣服入镜、背景尽量干净；条件允许时优先 MediaPipe 引擎 |

## 技术架构

```
摄像头(OpenCV VideoCapture) ──> 识别引擎(MediaPipe HandLandmarker 双手 / 肤色+凸包缺陷)
        │                              │ 每只手 21 关键点 + 左右手判定
        ▼                              ▼
   画面标注预览  <──  手势解释器（右手→光标移动；左手→点击/滚轮/拖拽）
                            │         EMA 平滑 + 防抖 + 冷却状态机
                            ▼
                   Win32 鼠标控制（ctypes: SetCursorPos / mouse_event）
```

- 双手模式：右手食指尖驱动光标，左手手势触发动作（单击/右键/双击/滚轮/拖拽），拖拽时双手配合可拖动窗口
- 左右手判定：MediaPipe 按手性标注（镜像画面自动翻转）；肤色引擎按画面左右位置近似
- 采集/识别/控制运行在后台线程，tkinter 主线程仅负责渲染，画面流畅不卡 UI
- 参数（灵敏度、模式等）改动即时生效并自动保存到 `settings.json`
